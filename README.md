

# SpliTrip

Aplicación web para planificar viajes, gestionar gastos compartidos y organizar las cuentas entre viajeros. Permite centralizar la información del viaje, controlar el presupuesto y calcular automáticamente los saldos pendientes entre participantes.

## Funcionalidades

- **Gestión de viajes:** Configuración del destino y las fechas.
- **Control de gastos:** Añadir, editar y eliminar gastos de transporte, alojamiento y actividades.
- **Gestión de viajeros:** Añadir y administrar los participantes.
- **División de gastos:** Repartir gastos entre todos los viajeros, una persona o un grupo específico.
- **Resumen financiero:** Consultar el presupuesto, el gasto total, el desglose por categorías y los saldos individuales.
- **Liquidación de cuentas:** Calcular automáticamente quién debe pagar y quién debe recibir dinero.
- **Itinerario:** Organizar reservas y actividades en orden cronológico.
- **Información de reservas:** Guardar referencias, datos de contacto y fechas límite de cancelación.
- **Almacenamiento local:** Guardar automáticamente los datos en el navegador mediante LocalStorage.
- **Diseño responsive:** Adaptado a dispositivos móviles y escritorio.

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- Web Storage API (LocalStorage)

## Instalación y ejecución

No requiere dependencias ni instalación adicional.

1. Clonar el repositorio:

   ```bash
   git clone <url-del-repositorio>
   ```

2. Abrir el archivo `index.html` en el navegador.

## Almacenamiento de datos

La información de los viajes se guarda localmente en el navegador mediante LocalStorage. No requiere registro de usuario ni conexión a un servidor.
